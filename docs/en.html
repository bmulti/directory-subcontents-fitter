[intro] # Directory Subcontents Fitter — what this application does Directory Subcontents Fitter examines folders, finds files using name and extension filters, moves files into subdirectories and finds duplicate files. It provides an Explorer, extension-based moves, a selected-file moving area, and checksum-based duplicate inspection. Files are not moved or deleted just by searching for them. Start with Explorer to examine a folder. Use Move by Extension to organize files into folders named after their extensions, or Move to Sub Directory to review a specific selection and its destinations before moving. Use De-DeDuplicate to identify matching files before deciding which to delete. Please make a backup of important data before moving, renaming or deleting files. A file move changes its location. Duplicate deletion is permanent. Right-click a folder and use Add to archive or ZIP, or copy the folder to another location before making extensive changes. Please be patient during large directory scans and checksum comparisons. [tab:explorer] # Explorer Enter a Directory or choose Browse, then click Find. The table displays matching filenames, modification dates, extensions and sizes. Select files using Select All or clear the selection with Select None. Double-click a file to open it with its associated application; Markdown files may open with the companion Markdown viewer when available. Starts with matches the beginning of a filename. Contains matches text anywhere within its filename. Extensions restricts results to specified file types, such as py, txt or jpg. Separate multiple extensions with commas, semicolons or spaces. Matching is not case sensitive. Recursive includes files in subfolders; with Recursive off, only files directly in the selected directory are listed. Click a column heading to change the sorting order. [tab:move-by-extension] # Move by Extension Choose the Downloads directory or another source folder with Browse. Enter optional Starts with, Contains and Extensions filters, choose Recursive if subfolders should be included, then click Find to review matching files. Select All and Select None control the current selection. Move Selected moves only highlighted entries. Move All moves every listed entry. Each file goes into a subfolder named for its extension in the file's original parent folder: a PDF file goes into pdf, for example. A file with no extension goes into no_extension. The program lists the proposed moves and asks for confirmation. It asks separately before overwriting any existing destination file. [tab:move-to-sub-directory] # Move to Sub Directory Choose a Source directory with Browse. Use Starts with, Contains, Extensions and Recursive to narrow the search, then click Find. Matching files appear in the upper table. Add Selected adds highlighted matches to the lower table; Add All adds every match. Adding a file does not move it. The New subdirectory field controls the destination folder inside the selected Source directory. After adding files, its default comes from the first Python file stem in the lower list. If no Python file is present, the Starts with text is used, followed by Contains; otherwise it stays empty. The name can be edited. The lower table shows each proposed destination. Remove Selected takes highlighted files out of the lower list without changing them on disk. Clear List empties the lower list. Rename Selected changes the destination filename for one highlighted file; it does not immediately rename the original. Move Selected moves highlighted entries from the lower list. Move All moves all entries in that lower list. The Add shared_path to moved Python files when missing option is enabled by default. When enabled, moving a Python file may also insert shared_path import setup into that file if the code is missing. Turn this option off if Python source must not be modified. Proposed moves are logged and need confirmation. Existing destination files require separate overwrite confirmation; a move does not automatically create a backup. [tab:de-deduplicate] # De-DeDuplicate Choose a Directory and click Find Duplicates to compare file contents. Matching file sizes are checked using SHA256 checksums. Files in the same duplicate group have matching checksums. The table shows each group, filename, location, size and checksum. Recursive includes subfolders. User files only excludes names or folders beginning with a dot. Minimum bytes and Maximum bytes limit the file sizes to inspect; an empty maximum has no upper limit. Starts with, Contains and Extensions further restrict the search. First Duplicates selects the extra copies while leaving the first listed file in each group unselected. Last Duplicates selects the extra copies while leaving the last listed file in each group unselected. Select None clears the selection. Check the selected paths before using Delete Selected. Delete Selected permanently removes the highlighted files after a confirmation showing their paths. The application warns if every copy in a duplicate group is selected, but it does not prevent the deletion. Deletion cannot be undone. Keep a separate backup of anything important. [tab:log] # Log The Log records actions, proposed file moves, confirmations, errors and results during the current session. Enter text in Search to highlight matching entries. Matching lines only hides entries without that text. Clear Log removes the displayed session entries. The session log is not written to a log file and is cleared when the application closes. [tab:config] # Config Config displays the location of cpc_dir_sub_fit.json, which stores application settings. Choose or enter Last directory, then click Load Directory to open it in Explorer. The application stores such settings as the last location, selected tab, filters, sorting and window appearance. [tab:ui-choices] # UI Choices Choose the interface theme, spacing or density and window dimensions. Depending on the available shared UI Choices module, controls may also include Use Current Size and Apply + Save. These settings affect the appearance of the application, not the contents of the selected files. [tab:gateway] # Gateway Use the shared Gateway launcher, when available, to access registered applications, files, folders or links. Gateway operates separately from Explorer searches, file moves and duplicate deletion.
